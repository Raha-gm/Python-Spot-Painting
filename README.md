# Python Spot Painting 🎨

A creative drawing project built with Python's Turtle graphics module.

This program generates colorful circular patterns using randomly generated RGB colors.

## Features

- Random RGB color generation
- Colorful dot patterns
- Circular geometric arrangements
- Python Turtle graphics
- Automatic pattern generation

## Technologies Used

- Python
- Turtle Graphics
- Random Module

## How to Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open the project folder.
4. Run the following command:

```bash
python main.py
```

## Requirements

No external libraries are required.

The project uses Python's built-in `turtle` and `random` modules.

## Preview

Run the program to generate a colorful spot painting.

Click on the Turtle window to close it.
